# جرد ومتابعة قسم الأشعة

موقع (PWA) باللغة العربية لجرد المواد الشهري والصرفيات وإحصائية الفحوصات والرواتب في قسم الأشعة.
يعمل على الهاتف والآيباد والحاسبة، ويحفظ البيانات في Firebase، ويعمل بدون إنترنت ثم يزامن تلقائيًا.

## الصفحات
- **الرئيسية:** فحوصات الشهر (ملونة وعادية)، المبلغ الكلي، حالة المخزون، رسوم آخر 12 شهر، والأشهر غير المكتملة.
- **الجرد:** لكل مادة: المدوّر (تلقائي من الشهر السابق)، أعداد الفحوصات، المصروف، الشراء، البيع، التالف، والمتبقي الفعلي، مع حساب الفرق بين المتبقي الفعلي والمحسوب.
- **الإحصائية:** عدد ومبالغ كل جهاز (MRI، CT، التقارير، X-Ray) وعمل كل موظف.
- **الرواتب:** حقول قابلة للإضافة (إضافة أو خصم) والصافي لكل موظف.
- **التقارير:** جداول سنوية ورسوم وتصدير Excel.
- **الإعدادات:** المواد، الموظفون، المستخدمون والصلاحيات، استيراد وتصدير JSON.

## الصلاحيات
| الدور | الصلاحية |
|---|---|
| صاحب الموقع / admin | كل شيء |
| manager (مدير المركز) | اطلاع على كل شيء + تعديل الرواتب وحقولها |

## التشغيل محليًا
```bash
npm install
npm run dev
```
ما دام `apiKey` فارغًا في `src/firebase-config.js` يعمل الموقع في **الوضع التجريبي** (البيانات على الجهاز فقط).

## الربط بـ Firebase والنشر
الموقع مربوط بمشروع Firebase `mri-department`، ويُنشر تلقائيًا على GitHub Pages عند كل دمج في `main`:
https://kbs7s.github.io/mri-department/

إعدادات تُعمل مرة واحدة:
1. **GitHub:** Settings > Pages > Source = **GitHub Actions**.
2. **Firebase > Authentication:** فعّل Email/Password، وأضف `kbs7s.github.io` في Settings > Authorized domains.
3. **Firebase > Firestore > Rules:** الصق محتوى `firestore.rules` واضغط Publish.
4. افتح الموقع واختر "حساب جديد": **أول حساب يسجل يصبح صاحب الموقع** بصلاحية كاملة.
5. من الإعدادات: استورد ملف البيانات السابقة، وأضف بريد مدير المركز.

> ملف البيانات السابقة لا يُحفظ في هذا المستودع لأنه عام.
